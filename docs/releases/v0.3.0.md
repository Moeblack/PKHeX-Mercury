# PKHeX Mercury v0.3.0 发行说明

发布日期：随 v0.3.0 发布（暂拟 v0.3.0，如远端标签被占用由维护者调整）。

下载：`PKHeX-Mercury-v0.3.0-win-x64.zip`（GitHub Releases，仓库 `Moeblack/PKHeX-Mercury`，标签 `mercury-v0.3.0`）。

## 亮点

- **原生 PKHeX 桌面界面**：使用上游 WinForms 主窗口与编辑控件，操作沿用 PKHeX 习惯。
- **内置水银 1.1 资料**：数值 profile、字表、地点、精灵图像与遭遇资料随应用提供，内存加载。
- **直接打开存档**：只需 `.srm` / `.sav`；**无需 ROM、字表、profile 或 JSON 导入**。
- 确认的水银存档统一按 1.1 读取；不从存档推断旧版本，不影响未改版火红 / 叶绿的原生识别。

## 使用方式

打开 → 右键**查看** → 修改左侧字段 → 右键目标格**设置** → 文件菜单**导出**。

## 功能范围

- 25 盒 × 30 格与 6 格队伍；编辑种类、昵称、初训家、PID、TID/SID、性别、性格、闪光、特性、持有物、亲密度、蛋标志、招式 / PP / IV / EV / 等级 / 经验、球与相遇信息、训练家信息、道具（含 PC）。
- 普通与闪光精灵图像：完整资源帧 / 调色板页只读预览，含 338 运行态与内部资源索引 0x0134 的 PID 斑点后处理。
- 未知图腾等特殊形态按已证机制分类并接入原生提示。
- 水银有依据的合法性检查（单只与批量原生入口）。

## 已知问题

- **729 号道具图像缺失**（外部阻塞，等待有效资源来源）；名称与数量仍可编辑。
- **合法性仍为部分**：普通获取全集、进化前 / 蛋招式组合、变化后的配信未识别来源仍为 Unknown；未知不代表合法，不提供完整合法结论。
- 不提供游戏战斗动画复刻或背面查看器；仅资源帧 / 页预览。
- 第 20–22 箱缺少非空真实存档样本；未做游戏实测。
