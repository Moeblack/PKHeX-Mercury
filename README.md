# PKHeX Mercury · 宝可梦水银版

宝可梦水银1.1存档编辑器，沿用PKHeX的中文界面和盒子操作方式。

## 下载与启动

**[下载 v0.2.0 Windows x64 便携包](https://github.com/Moeblack/PKHeX-Mercury/releases/download/mercury-v0.2.0/PKHeX-Mercury-v0.2.0-win-x64.zip)** · 约78 MiB

解压 `PKHeX-Mercury-v0.2.0-win-x64.zip`，运行其中的 **`PKHeX.exe`**，无需另装.NET。窗口标题保留上游版本号 `20260826`；本包的水银发行版本为v0.2.0。

## 第一次使用

v0.2.0需要准备两份文件：你使用的**水银1.1 `.gba`游戏文件**，以及该游戏的**`.srm`或`.sav`存档**。

### 1. 准备存档

先在游戏菜单中保存，再退出模拟器，让进度写入存档文件。

- RetroArch通常把游戏内存档放在配置的 `saves` 目录，扩展名为 `.srm`。
- mGBA使用 `.sav`；具体位置取决于模拟器的存档目录设置。
- 用模拟器的“保存状态/Save State”产生的是即时存档，不是这里需要的游戏内存档。

本版读取128 KiB存档，也读取附带16字节RTC信息的存档；无需手工删除尾部或更改扩展名。

### 2. 配置游戏资料

打开 **工具 → 水银 → 从 ROM 生成配置**，选择自己的水银1.1 `.gba`。程序读取其中的数值与图片，游戏文件保持不变。

如果名称显示不完整，在同一菜单选择**下载公开HOME字表**；已有字表的用户可选择导入JSON、`game_data.js`或HTML。字表用于显示中文名称，数值仍取自游戏文件。配置或字表改变后，重新打开存档以刷新界面。

资料自动保存于 `%LOCALAPPDATA%\PKHeX-Mercury\profile\`，以后启动自动加载。菜单中的“加载已有配置文件夹”和“导入解包研究目录”供迁移资料或开发使用，首次使用不需要这些目录。

若提示ROM版本不匹配，本版暂不支持该文件。需要核对时，可在PowerShell执行：

```powershell
Get-FileHash "你的游戏文件.gba" -Algorithm SHA256
```

v0.2.0对应的文件大小为33,554,432字节，SHA-256为：

```text
131b009df7ab252deff0d6a0518ab82f88e82c940ee68d50d31033a899f7e3dd
```

### 3. 打开、编辑、导出

1. 用 **文件 → 打开** 载入 `.srm`或`.sav`。
2. 如果出现格式选择：从水银游戏保存的文件选**宝可梦水银**；从未改版火红/叶绿等游戏保存的文件选对应原版。文件来源不清楚时取消选择，先确认它由哪个游戏产生。
3. 在盒子或队伍中右键目标宝可梦，选择**查看**，把它载入左侧编辑区。
4. 修改左侧字段后，右键需要写入的目标格，选择**设置**。这一步更新程序内的存档；只修改左侧字段不会自动替换目标格。
5. 从**文件菜单导出存档**，在保存对话框选择输出文件。要保留原文件，就使用新的文件名。
6. 关闭模拟器后，将导出的文件放回它实际使用的存档位置，并保持与游戏匹配的文件名；重新启动游戏读取进度。

新建、删除、拖放及盒子切换使用PKHeX现有控件。单体宝可梦可通过预览图的文件导出操作保存，使用 `.mercurypkm`；重新打开该文件可载入编辑区，再用“设置”放入目标格。旧的58字节 `.m3box` 记录仍可导入。水银单体与原版 `.pk3` 是不同格式。

## 本版功能

- 25个盒子，每盒30格；6格队伍。
- 种类、昵称、初训家、PID、TID/SID、性别、性格、闪光、特性、持有物、亲密度和蛋标志。
- 招式、PP、PP提升、个体值、努力值、等级和经验。
- 精灵球、相遇信息、病毒及标记。
- 训练家名称、性别、ID、金钱、代币及游戏时间。
- 普通道具、关键道具、球、技能机、树果及PC道具。
- 普通与闪光精灵图片；当前显示首帧、首调色板页。

## 已知问题

以下状态对应已发布的v0.2.0；源码中的后续修改见[开发问题清单](docs/mercury-issues.md)。

| 情况 | 使用时的影响 |
|---|---|
| 未知图腾及部分特殊形态未适配 | 字母图片与形态选择不完整。 |
| 729号道具图像缺失 | 该道具可能显示空图标，名称及数量仍可编辑。 |
| 水银合法性检查暂停 | 编辑和导出仍可使用，但程序不会判断获取途径或配招是否合法；原版存档检查照常工作。存档校验和及字段范围检查仍生效。 |
| 部分球、来源或地点只有编号 | 对应名称或含义仍在整理，界面保留已有值。 |
| 多帧与特殊状态图片不完整 | 预览可能与游戏某些运行状态不同。 |
| 版本支持有限 | 当前只识别上述水银1.1文件，首次使用需要自行配置ROM和字表。 |

盒子显示与切换、道具窗口、默认中文昵称及部分内存读写路径已有检查。第20–22箱缺少非空真实存档样本；完整的实机回写与所有交互组合仍待覆盖。

反馈问题时，请提供发行版本、操作步骤、错误文字或截图，以及使用的模拟器名称。

## 开发者资料

普通使用不需要阅读存档偏移或编写配置文件。开发入口：

- [适配问题与进度](docs/mercury-issues.md)
- [存档布局和ROM消费者](docs/mercury-save-format.md)
- [数据接口、字表和资源格式](docs/mercury-rom-profile.md)

使用.NET 10 SDK构建：

```powershell
dotnet build PKHeX.Mercury.slnx -c Release
dotnet publish PKHeX.WinForms/PKHeX.WinForms.csproj -c Release -r win-x64 --self-contained true -o artifacts/native-publish
```

`PKHeX.Mercury.slnx`构建上游主窗口、绘图项目和水银适配器。旧独立界面不进入当前发行构建。
