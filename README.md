# PKHeX Mercury · 宝可梦水银版

宝可梦水银 1.1 存档编辑器，沿用 PKHeX 原生桌面界面（WinForms）与盒子操作方式。

## 下载与启动

**[下载 v0.3.0 Windows x64 便携包](https://github.com/Moeblack/PKHeX-Mercury/releases/download/mercury-v0.3.0/PKHeX-Mercury-v0.3.0-win-x64.zip)**

解压 `PKHeX-Mercury-v0.3.0-win-x64.zip`，运行其中的 **`PKHeX.exe`**，无需另装 .NET。窗口标题保留上游版本号 `20260826`；本包的水银发行版本为 v0.3.0。

[发行说明](docs/releases/v0.3.0.md) · [所有发行](https://github.com/Moeblack/PKHeX-Mercury/releases) · [报告问题](https://github.com/Moeblack/PKHeX-Mercury/issues)

## 第一次使用

v0.3.0 **只需准备你的水银存档**：`.srm` 或 `.sav`。水银 1.1 的数值、字表、地点、精灵图像与遭遇资料已**内置**，无需提供 ROM，也无需下载字表或导入 JSON。

### 1. 准备存档

先在游戏菜单中保存，再退出模拟器，让进度写入存档文件。

- RetroArch 通常把游戏内存档放在配置的 `saves` 目录，扩展名为 `.srm`。
- mGBA 使用 `.sav`；具体位置取决于模拟器的存档目录设置。
- 用模拟器的“保存状态 / Save State”产生的是即时存档，不是这里需要的游戏内存档。

本版读取 128 KiB 存档，也读取附带 16 字节 RTC 信息的存档；无需手工删除尾部或更改扩展名。

### 2. 游戏资料（内置 1.1）

本版面向已确认的水银存档，统一使用**内置的水银 1.1 资料**（数值 profile、字表、地点、精灵图像、遭遇资料），从内存加载，资料随应用更新。普通使用**不需要** ROM、字表、profile 或 JSON 导入；内置资料优先于本机旧缓存。

本版不从存档推断旧版本，也不影响未改版火红 / 叶绿存档的原生识别与格式选择。发行包包含由水银 1.1 提取的资料，但**不包含完整游戏 ROM 或个人存档**。

### 3. 打开、查看、设置、导出

1. 用 **文件 → 打开** 载入 `.srm` 或 `.sav`。若出现格式选择：从水银游戏保存的文件选**宝可梦水银**；从未改版火红 / 叶绿等游戏保存的文件选对应原版。
2. 在盒子或队伍中**右键目标宝可梦 → 查看**，把它载入左侧编辑区。
3. 修改左侧字段后，**右键需要写入的目标格 → 设置**。只修改左侧字段不会自动替换目标格。
4. 从**文件菜单导出存档**，在保存对话框选择输出文件；要保留原文件就使用新文件名。
5. 关闭模拟器后，把导出的文件放回它实际使用的存档位置，保持与游戏匹配的文件名，重新启动游戏读取进度。

新建、删除、拖放及盒子切换使用 PKHeX 现有控件。单体宝可梦可通过预览图的文件导出操作保存为 `.mercurypkm`；重新打开可载入编辑区，再用“设置”放入目标格。旧的 58 字节 `.m3box` 记录仍可导入。水银单体与原版 `.pk3` 是不同格式。

## 本版功能

- 25 个盒子（每盒 30 格）与 6 格队伍；查找、复制、移动、克隆、新建。
- 种类、昵称、初训家、PID、TID/SID、性别、性格、闪光、特性、持有物、亲密度与蛋标志。
- 招式、PP、PP 提升、个体值、努力值、等级与经验。
- 精灵球、相遇信息、病毒及标记。
- 训练家名称、性别、ID、金钱、代币与游戏时间。
- 普通道具、关键道具、球、技能机、树果及 PC 道具。
- 普通与闪光精灵图像：完整资源帧 / 调色板页只读预览，含 338 运行态与内部资源索引 0x0134 的 PID 斑点后处理。
- 未知图腾等特殊形态按已证机制分类，并接入原生提示。
- 水银有依据的合法性检查（单只与批量原生入口）。

## 已知问题

| 情况 | 使用时的影响 |
|---|---|
| 729 号道具图像缺失 | 该道具可能显示空图标，名称与数量仍可编辑；属外部阻塞，等待有效资源来源。 |
| 合法性仍为部分 | 检查只覆盖有依据的范围；**普通获取全集、进化前 / 蛋招式组合、变化后的配信未识别来源**仍为 Unknown（未知）。未知不代表合法，程序不会伪造完整合法结论。 |
| 部分球、来源或地点只有编号 | 对应名称或含义仍在整理，界面保留已有值。 |
| 多帧与特殊状态图片 | 仅提供资源帧 / 页只读预览，不复刻游戏战斗动画，不提供背面查看器。 |
| 版本支持 | 当前只识别水银 1.1。 |

盒子显示与切换、道具窗口、默认中文昵称及部分内存读写路径已有检查。第 20–22 箱缺少非空真实存档样本；完整的实机回写与所有交互组合仍待覆盖；**未做游戏实测**。

反馈问题时，请提供发行版本、操作步骤、错误文字或截图，以及使用的模拟器名称。

## 开发者资料

普通使用不需要阅读存档偏移或编写配置文件。开发入口：

- [适配问题与进度](docs/mercury-issues.md)
- [存档布局和 ROM 消费者](docs/mercury-save-format.md)
- [数据接口、字表和资源格式](docs/mercury-rom-profile.md)

使用 .NET 10 SDK 构建：

```powershell
dotnet build PKHeX.Mercury.slnx -c Release
dotnet publish PKHeX.WinForms/PKHeX.WinForms.csproj -c Release -r win-x64 --self-contained true -o artifacts/native-publish
```

`PKHeX.Mercury.slnx` 构建上游主窗口、绘图项目和水银适配器。旧独立界面不进入当前发行构建。
